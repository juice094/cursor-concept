# Phase 0 验证报告

## 静态光标提取与矢量化（v1 → v2 优化）

### 原始矢量化（v1）问题发现

原始使用 `vtracer` CLI `binary` 模式直接处理提取的 PNG，存在以下系统性质量问题：

| 问题 | 影响文件 | 描述 |
|------|---------|------|
| **背景矩形填充** | dark/person, dark/pin, light/person, light/pin 等 | 首 path 为 `M0 0 C31.68...` 全画布填充，实际图标被淹没 |
| **多 path 噪点** | dark/pointer (2→1), dark/help (11→1) | 零散小点/残片被误认为独立 shape |
| **热点偏移** | 全部 | 未处理 .cur 热点坐标，SVG 默认左上角对齐 |

### 优化方法（v2）

`scripts/optimize_cursor.py`：
1. **预处理**：Pillow 亮度分析 + 自定义阈值二值化（替代 vtracer 内置 binary）
2. **透明背景**：将背景像素设为纯白/纯黑，前景设为对比色，消除边缘误判
3. **矢量化参数优化**：
   - `mode='spline'` — 平滑曲线
   - `filter_speckle=3` — 过滤 3px 以下噪点
   - `length_threshold=6` — 控制线段细分
   - `corner_threshold=120` — 允许较大圆角（光标风格）

### 关键改善

- ✅ **全部 30 个 SVG 消除背景矩形填充**
- ✅ **path 数量显著减少**：help 11→1, pointer 2→1
- ✅ **文件大小平均减少 20%**（消除冗余 path）
- ⚠️ **person/pin/vert 文件增大**：因 v1 版本实际为空/残缺，v2 正确提取了完整图标
- ⚠️ **热点坐标**：仍需从原始 .cur 文件读取并注入 SVG
